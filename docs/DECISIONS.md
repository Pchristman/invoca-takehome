| 2026-11-18 | PROPOSED, awaiting review: three reasons beyond rule 3: `missing_call_id`, `bad_duration` (negative, empty or non-integer), `bad_revenue` (non-numeric or negative) | Without them an empty id merges unrelated calls and a bad number becomes NaN in a total | Letting these through; crashing |
| 2026-11-18 | PROPOSED, awaiting review: bad campaigns/locations rows (empty or duplicate id, bad budget) are skipped and reported; a location with an invalid IANA zone is kept so its calls report `invalid_timezone` | Keeps "bad rows never crash" true for the reference files; matches rule 3 on invalid zones | Failing startup on any bad reference row |

| 2026-11-18 | Keep a byte copy of the shipped export in `tests/fixtures/original-export/` for snapshot tests; repo-root CSVs stay untouched | BRIEF.md asks for a regression fixture; the root files are also the default `DATA_DIR` | Testing against the root files only |
| 2026-11-18 | PROPOSED, awaiting review: a seventh bad reason, `inconsistent_outcome`: answered=false with booked/qualified_lead/not_qualified, or answered=true with missed/voicemail. | 2026-11-18 | Time zones: tzdb aliases (EST, US/Arizona, any case) are accepted and stored under Intl's canonical name; UTC-offset strings (`+05:00`) are invalid | Aliases are IANA identifiers; offsets have no daylight saving and are not IANA zones | Accepting whatever `Intl` accepts; rejecting all aliases |
| 2026-11-18 | CSV parsing: any of LF, CRLF or CR ends a row; a stray quote inside a field is kept as text; only an unclosed quote or a repeated required header stops startup | A mixed-ending file silently merged rows, and one stray quote blocked startup for the whole export | csv-parse defaults; a new bad reason for malformed rows |

| 2026-11-18 | `.gitattributes` has `*.csv -text`; the shipped export is CRLF and is stored that way | `core.autocrlf` had stored the fixture as LF, so a clone was not the original bytes | Per-machine autocrlf settings |
